🔐 User Authentication & CRUD System

📌 Project Description

A web-based application built using Python and Streamlit that allows users to sign up, log in, and manage records through CRUD operations.

✨ Features

- User Registration and Login
- Password Hashing
- Create, Read, Update, and Delete Records
- SQLite Database Integration
- Interactive Dashboard
- Session Management
- Input Validation

🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Hashlib

⚙️ How to Run

Install Streamlit:

pip install streamlit

Run the application:

streamlit run first.py

📂 Project Structure

User-Authentication-CRUD/
├── first.py
└── README.md

Note: The SQLite database file ("database.db") is automatically created when the application runs.

🎯 Learning Outcomes

Python programming, authentication, database connectivity, CRUD operations, and Streamlit application development.
